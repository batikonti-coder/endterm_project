# Travel Site - Endterm Project

## Project Overview
This project is an interactive continuation of our midterm travel website. We have enhanced the user experience by integrating advanced JavaScript and jQuery features while maintaining the fully responsive HTML, CSS, and Bootstrap structure from the midterm phase.

## Team
* **Батырхан** - Group SE-2524
## New Endterm Features
1. **Dynamic Content Rendering:** Travel destinations are loaded dynamically from JavaScript arrays.
2. **Interactive Search:** Real-time filtering of destinations using event listeners.
3. **Theme Switcher:** A dark/light mode toggle modifying DOM classes.
4. **Favorites System:** Users can add destinations to a temporary favorites array.
5. **Form Validation:** The booking form features custom logic to validate email formats and name length, preventing default submission until errors are cleared.
6. **jQuery FAQ Accordion:** Interactive collapsible sections built with jQuery DOM traversal (`.next()`, `.parent()`, `.siblings()`) and animations (`slideToggle()`).

## How to Test
1. Type in the search bar on the Destinations page to see real-time filtering.
2. Click "Add to Favorites" to see the button state update dynamically.
3. Try submitting the booking form with empty or invalid inputs to trigger validation messages.
4. Click on the FAQ questions to see jQuery slide effects.
